# NextQuest

NextQuest는 소울라이크 게임 구매를 고민하는 사용자가 검수된 리뷰 분석과 자신의 과거 플레이 경험을 비교해, 후보 게임이 어떤 요소에서 취향과 일치하거나 충돌하는지 판단하도록 돕는 서비스입니다.

## 처음 읽는 순서

1. [프로젝트 컨텍스트](docs/project-context.md): 해결하려는 문제, 대상 사용자, 핵심 가치
2. [MVP 범위](docs/product/scope.md): 포함 범위, 제외 범위, 지원 게임
3. [대표 사용자 흐름](docs/product/user-flow.md): 기본 분석부터 개인화 비교와 저장까지의 흐름
4. [작업 인수인계](HANDOFF.md): 현재 진행 상태, 다음 작업과 재개 절차
5. [개발 계획](docs/product/development-plan.md): 개발 순서와 마일스톤별 완료 조건
6. [리뷰 분석 정책](docs/product/review-analysis.md): 리뷰 표본, 특성 분류, 근거, 번역과 갱신 정책
7. [Steam API 계약](docs/technical/steam-api-contract.md): 공식 응답 구조와 fixture 변환 경계
