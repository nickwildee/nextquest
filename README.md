# NextQuest

NextQuest는 소울라이크 게임 구매를 고민하는 사용자가 검수된 리뷰 분석과 자신의 과거 플레이 경험을 비교해, 후보 게임이 어떤 요소에서 취향과 일치하거나 충돌하는지 판단하도록 돕는 서비스입니다.

## 프로젝트 문서

- [프로젝트 컨텍스트](docs/project-context.md): 해결하려는 문제, 대상 사용자, 핵심 가치
- [MVP 범위](docs/product/scope.md): 포함 범위, 제외 범위, 지원 게임
- [대표 사용자 흐름](docs/product/user-flow.md): 기본 분석부터 개인화 비교와 저장까지의 흐름
- [개발 계획](docs/product/development-plan.md): 개발 순서와 마일스톤별 완료 조건
- [작업 인수인계](HANDOFF.md): 현재 진행 상태, 확정된 결정과 구현 전 미결정 항목
