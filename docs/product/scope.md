# NextQuest MVP 범위

## 목적

MVP는 사용자가 소울라이크 게임의 리뷰를 빠르게 이해하고, 자신의 과거 플레이 경험과 비교해 구매 판단을 더 명확하게 내릴 수 있는지 검증한다.

## 포함 범위

### 기본 리뷰 분석

- 로그인하지 않은 사용자도 검수된 게임 목록과 기본 리뷰 분석을 볼 수 있다.
- 게임의 리뷰를 전투, 조작, 보스전, 탐험, 성장·빌드, 파밍·반복 플레이의 6개 요소로 구조화한다.
- 긍정·부정 리뷰에서 반복적으로 나타나는 특성을 함께 제공한다.
- 모든 노출 분석 항목에 실제 리뷰 근거를 연결한다.
- 실시간 분석 대신 미리 분석하고 검수한 결과를 제공한다.

### 사용자 온보딩

- Steam 계정 연동은 선택 사항으로 제공한다.
- 연동 시 Steam 라이브러리와 플레이 시간을 불러온다.
- 새 Steam 계정, 비공개 라이브러리, 다른 플랫폼 플레이 경험을 위해 수동 등록 경로를 제공한다.
- 수동 등록은 Steam에 정식 등록된 검수 게임으로 제한한다.
- 수동 등록 시 플레이한 플랫폼과 플레이 시간 구간을 사용자가 직접 입력한다.
- 비교 기준 게임은 Steam 공식 상점에서 한국어 인터페이스를 지원해야 한다.
- 한국어 자막과 한국어 음성 지원은 필수 조건으로 두지 않는다.
- 충분한 플레이 경험 기준을 충족한 소울라이크·인접 장르 게임만 비교 기준으로 사용할 수 있다.
- 사용자는 비교 기준 게임을 최소 3개 선택한다.
- 각 게임에서 6개 요소를 모두 `좋았음` 또는 `아쉬웠음`으로 평가한다.

### 개인화 비교

- 비교 기준 게임 3개 평가를 완료한 사용자에게만 개인화 비교를 활성화한다.
- 후보 게임의 6개 요소를 사용자 취향과 비교한다.
- 마이페이지에서 비교 기준 게임의 6개 요소 평가를 확인하고 수정할 수 있다.
- 평가를 수정하면 최신 사용자 입력을 기준으로 개인화 결과를 다시 계산한다.
- 종합 적합도 점수는 제공하지 않는다.
- 결과를 `맞을 근거`, `주의 신호`, `판단 불가`로 구분한다.
- 각 결과에 판단 근거가 된 실제 리뷰를 연결한다.
- 사용자 입력이나 리뷰 근거가 부족하거나 충돌하면 `판단 불가`로 표시한다.

### 구매 판단 관리

- 분석한 게임을 `구매 후보`, `보류`, `제외` 중 하나로 저장한다.
- 마이페이지에서 상태별 게임 목록을 확인한다.
- 상태는 사용자의 직접 판단이며 시스템이 자동으로 결정하지 않는다.

## MVP 제외 범위

- 사용자의 취향에 맞는 게임을 자동으로 추천하는 피드
- 두 개 이상의 후보 게임을 직접 비교하는 기능
- 모든 Steam 장르와 게임 지원
- Steam에 등록되지 않은 콘솔 전용 게임 등록
- 가격 변동, 할인 알림, 위시리스트 자동 연동
- 친구와 게임 취향 비교
- 사용자 요청 시 실행하는 실시간 리뷰 분석
- 리뷰의 과거·최근 추세 비교와 패치 전후 변화 판단
- 머신러닝 추천 모델과 파인튜닝
- 관리자용 리뷰 라벨링·분석 관리 도구
- 실제 구매 여부와 장기 플레이 결과 자동 추적
- 구매 판단에 대한 자유 메모
- 외부 웹진이나 다른 플랫폼의 게임 정보 크롤링

## 성공 기준

### 기능적 성공 기준

- 로그인하지 않은 사용자가 8개 게임의 기본 리뷰 분석과 근거를 확인할 수 있다.
- 조건을 충족한 사용자가 온보딩부터 개인화 비교와 구매 상태 저장까지 대표 흐름을 완료할 수 있다.
- 과거 경험 평가를 수정하면 개인화 결과가 최신 입력을 반영한다.
- 조건을 충족하지 못한 사용자도 기본 리뷰 분석을 이용할 수 있으며, 필요한 조건을 명확히 안내받는다.
- 모든 개인화 결과에 실제 리뷰 근거가 연결된다.
- 핵심 사용자 흐름에 대한 E2E 테스트가 통과한다.

### 사용자 가치 검증 기준

소울라이크 경험이 있는 사용자 3명 이상에게 다음을 확인한다.

- 기본 분석이 Steam 개별 리뷰보다 게임의 장단점을 빠르게 파악하는 데 도움이 되는가?
- 과거 경험과의 비교가 구매 판단에 실질적인 영향을 주는가?
- `맞을 근거`, `주의 신호`, `판단 불가`의 차이를 이해할 수 있는가?
- 실제 리뷰 근거가 분석 결과를 신뢰하는 데 도움이 되는가?
- 분석 전보다 `구매 후보`, `보류`, `제외` 중 하나를 더 명확하게 선택할 수 있는가?

게임을 실제로 구매하고 장시간 플레이했는지는 장기 검증 항목으로 분리한다.

## 구현 전 결정할 정책

다음 항목은 제품 범위를 바꾸지 않는 세부 정책이므로 구현 전에 별도로 검증하고 결정한다.

- 충분한 플레이 경험으로 인정할 정확한 시간 기준
- 온보딩에 사용할 소울라이크·인접 장르 비교 기준 게임 목록
- 리뷰 표본 수, 언어 구성, 최신성 기준과 갱신 주기
- 사용자 인증, 데이터 저장, API, 데이터베이스, 세부 아키텍처
