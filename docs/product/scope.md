# NextQuest 내부검증용 fixture MVP 범위

## 목적

첫 MVP는 외부 서비스 연동 없이 NextQuest의 핵심 가치와 사용자 흐름을 빠르게 검증하는 내부 프로토타입이다. 사용자가 과거 게임 경험을 입력하고 후보 게임의 실제 리뷰 근거와 비교했을 때 구매 판단에 도움을 받는지를 먼저 확인한다.

Steam 연동, 운영 인증, 데이터베이스와 리뷰 처리 자동화는 이 흐름의 가치가 확인된 뒤 진행한다.

## 포함 범위

### fixture 기반 기본 리뷰 분석

- 검수된 게임, 리뷰 특성, 리뷰 근거와 사용자 라이브러리를 고정 fixture로 제공한다.
- 로그인하지 않은 사용자도 게임의 기본 리뷰 분석을 볼 수 있다.
- 분석은 전투, 조작, 보스전, 탐험, 성장·빌드, 파밍·반복 플레이의 6개 경험 요소로 구분한다.
- 모든 노출 분석 항목에 원문에서 잘라낸 실제 리뷰 근거를 연결한다.
- 정상 흐름의 근거 문장을 생성형 모델이 새로 작성하지 않는다.
- 오류, 빈 결과와 충돌 상태를 검증하는 자동 테스트 fixture에는 합성 문장을 사용한다.

리뷰 표본, 언어, 특성 분류와 근거 처리의 세부 기준은 [리뷰 분석 정책](review-analysis.md)이 책임진다.

### 프로토타입 로그인과 로컬 저장

- 기본 리뷰 분석은 로그인 없이 이용한다.
- 개인화 입력, 결과와 구매 판단 저장에는 fixture 로그인을 필수로 요구한다.
- 로그인은 실제 인증이 아닌 고정 사용자 전환으로 동작한다.
- 작성 중인 입력은 브라우저에 자동 저장하고 새로고침 후 복구한다.
- 사용자가 저장을 누르면 프로토타입의 완료 상태도 `localStorage`에 기록한다.
- 서버 전송, 계정 간 동기화와 다른 기기 동기화는 제공하지 않는다.

### 비교 기준 게임 등록

- 검수된 소울라이크·인접 장르 게임만 비교 기준으로 사용한다.
- 게임별 최소 플레이 시간과 사용자의 `충분히 플레이했다`는 확인을 함께 요구한다.
- 플레이한 플랫폼과 게임 언어는 비교 기준 자격에 영향을 주지 않는다.
- 한국어 인터페이스, 자막 또는 음성 지원 여부를 비교 기준 자격으로 사용하지 않는다.
- 조건을 충족한 비교 기준 게임이 최소 3개 있어야 개인화 비교를 시작할 수 있다.
- 조건을 충족하고 평가를 완료한 모든 비교 기준 게임을 개인화 계산에 사용한다. 사용자가 임의로 3개만 추려서 계산하지 않는다.

### 6개 경험 요소 필수 응답

각 비교 기준 게임에서 다음 요소에 모두 응답한다.

1. 전투
2. 조작
3. 보스전
4. 탐험
5. 성장·빌드
6. 파밍·반복 플레이

각 요소의 입력값은 다음과 같다.

- `좋았음`: 해당 요소를 긍정적인 취향 근거로 사용한다.
- `아쉬웠음`: 해당 요소를 부정적인 취향 근거로 사용한다.
- `경험 부족`: 필수 응답은 완료한 것으로 보지만 해당 게임·요소를 취향 계산에서 제외한다.

일부 요소를 `경험 부족`으로 응답해도 게임별 플레이 경험 조건을 충족했다면 최소 3개 게임의 개수에는 포함한다. 근거 충분성은 사용자 전체가 아니라 경험 요소별로 판단한다.

### 개인화 비교

- 후보 게임의 리뷰 특성과 사용자가 과거 게임에 입력한 평가를 경험 요소별로 비교한다.
- 리뷰 작성자의 긍정·부정은 후보 게임에 그 특성이 어떻게 받아들여졌는지를 설명한다.
- 사용자 자신의 `좋았음`과 `아쉬웠음`이 개인 취향의 방향을 결정한다.
- 결과는 `맞을 근거`, `주의 신호`, `판단 불가`로 구분한다.
- 한 경험 요소에 `맞을 근거`와 `주의 신호`가 동시에 존재할 수 있다.
- 사용자 입력, 비교 가능한 특성 또는 리뷰 근거가 부족하거나 의견이 충돌하면 해당 요소를 `판단 불가`로 표시한다.
- 종합 적합도 점수로 결과를 합치지 않는다.
- Steam 태그 유사성은 수동으로 검수한 태그 fixture를 사용해 작고 상한이 있는 가점만 준다. 태그가 다르다는 이유로 감점하지 않는다.

### 취향 반복과 일관성

특성의 강도를 하나의 `강함/약함` 값으로 만들지 않고 두 정보를 분리한다.

- **분포 범위**: 해당 경험 요소에 유효한 평가가 있는 비교 게임 중 그 특성이 확인된 게임의 비율
- **선호 일관성**: 그 특성이 확인된 게임에서 사용자가 `좋았음` 또는 `아쉬웠음`으로 얼마나 일관되게 평가했는지

분모는 사용자가 보유한 전체 게임이 아니라 해당 경험 요소에 유효한 평가가 있는 비교 기준 게임이다. 특성이 발견되지 않았다는 사실은 부정 근거로 사용하지 않는다. 한 게임에서만 발견된 특성은 잠정적인 취향 근거로 취급한다.

### 리뷰 근거 노출

- 결과마다 기본 3개의 대표 근거를 보여준다.
- 사용자가 더보기를 선택하면 최대 10개까지 보여준다.
- 대표 근거는 같은 말의 반복만 모으지 않고 주요 의견의 일관성과 서로 다른 관점을 함께 보여준다.
- 영어 근거는 검수된 한국어 번역과 원문을 함께 제공하고 AI 번역임을 표시한다.

### 구매 판단 관리

- 분석한 게임을 `구매 후보`, `보류`, `제외` 중 하나로 저장한다.
- 프로토타입 마이페이지에서 상태별 게임과 과거 경험 입력을 확인하고 수정한다.
- 상태는 사용자의 직접 판단이며 시스템이 자동으로 결정하지 않는다.

## 제외 범위

- 실제 Steam 계정과 라이브러리 연동
- 운영 사용자 인증과 OAuth
- 서버 저장, 데이터베이스, SQLite와 ORM
- 계정 기반 다른 기기 동기화
- 사용자 요청 시 실행하는 온라인 LLM 분석과 번역
- 자동 리뷰 수집·갱신과 패치 자동 감지
- 사용자의 취향에 맞는 게임을 자동으로 추천하는 피드
- 두 개 이상의 후보 게임을 직접 비교하는 기능
- 모든 Steam 장르와 게임 지원
- 가격 변동, 할인 알림과 위시리스트 자동 연동
- 친구와 게임 취향 비교
- 머신러닝 추천 모델과 파인튜닝
- 관리자용 리뷰 라벨링·분석 관리 도구
- 실제 구매 여부와 장기 플레이 결과 자동 추적
- 외부 웹진이나 다른 플랫폼의 리뷰 크롤링

## 성공 기준

### 기능적 성공 기준

- 사용자가 fixture 데이터만으로 기본 분석부터 구매 판단 저장까지 대표 흐름을 완료할 수 있다.
- 개인화 시작 전에 fixture 로그인이 요구된다.
- 조건을 충족한 비교 기준 게임 3개 이상에서 6개 요소를 모두 응답할 수 있다.
- `경험 부족`이 입력 완료에는 포함되지만 해당 요소의 취향 계산에서는 제외된다.
- 조건을 충족하고 평가를 완료한 모든 비교 게임이 개인화에 사용된다.
- 개인화 결과가 경험 요소별 `맞을 근거`, `주의 신호`, `판단 불가`로 구분된다.
- 한 경험 요소에서 맞을 근거와 주의 신호를 함께 표시할 수 있다.
- 모든 노출 결과에 원문에서 가져온 리뷰 근거가 연결된다.
- 작성 중인 입력과 저장한 상태가 새로고침 후 복구된다.
- 종합 적합도 점수가 화면이나 로직에 포함되지 않는다.
- 대표 흐름과 주요 예외 흐름에 대한 E2E 테스트가 통과한다.

### 사용자 가치 검증 기준

소울라이크 경험이 있는 내부 사용자에게 다음을 확인한다.

- 기본 분석이 Steam 개별 리뷰보다 게임의 장단점을 빠르게 파악하는 데 도움이 되는가?
- 6개 요소 입력이 자신의 선호와 비선호를 충분히 표현하게 하는가?
- 과거 경험과의 비교가 구매 판단에 실질적인 영향을 주는가?
- `맞을 근거`, `주의 신호`, `판단 불가`와 동시 존재를 이해할 수 있는가?
- 실제 리뷰 근거와 분석 범위가 결과를 검증하고 신뢰하는 데 도움이 되는가?

## 구현 전에 결정할 정책

- 게임별 최소 플레이 시간
- 내부 프로토타입에서 사용할 정확한 후보·비교 게임 fixture 구성
- 리뷰 특성 분류표의 세부 특성과 동의어
- 리뷰 배치의 안정화 판정식과 게임당 분석 상한
- 특성별 긍정·부정 우세를 표시할 최소 표본과 신뢰 기준
- 결과 화면과 구매 판단 상태의 최종 배치
- 내부 사용자 검증의 통과·실패 기준
- 실제 연동 단계의 인증, 서버 저장, API와 데이터베이스 구조
