# NextQuest MVP 범위

## 목적

MVP는 사용자가 소울라이크 게임의 리뷰를 빠르게 이해하고, 자신의 과거 플레이 경험과 비교해 구매 판단을 더 명확하게 내릴 수 있는지 검증한다.

## 포함 범위

### 기본 리뷰 분석

- 로그인하지 않은 사용자도 검수된 게임 목록과 기본 리뷰 분석을 볼 수 있다.
- 게임의 리뷰를 검수된 상위 경험 영역과 구체적인 하위 특성으로 구조화한다.
- 긍정·부정 리뷰에서 반복적으로 나타나는 특성을 함께 제공한다.
- 모든 노출 분석 항목에 실제 리뷰 근거를 연결한다.
- 실시간 분석 대신 미리 분석하고 검수한 결과를 제공한다.

### 사용자 온보딩

- Steam 계정 연동은 선택 사항으로 제공한다.
- 연동 시 Steam 라이브러리와 플레이 시간을 불러온다.
- 새 Steam 계정, 비공개 라이브러리, 다른 플랫폼 플레이 경험을 위해 수동 등록 경로를 제공한다.
- 수동 등록은 Steam에 정식 등록된 검수 게임으로 제한한다.
- 수동 등록 시 플레이한 플랫폼과 플레이 시간 구간을 사용자가 직접 입력한다.
- 비교 기준 게임은 Steam 공식 상점에서 한국어 인터페이스를 지원해야 한다.
- 한국어 자막과 한국어 음성 지원은 필수 조건으로 두지 않는다.
- 충분한 플레이 경험 기준을 충족한 소울라이크·인접 장르 게임만 비교 기준으로 사용할 수 있다.
- 사용자는 충분히 플레이했고 선호한 경험이 많으며 그 이유와 아쉬웠던 점을 구체적으로 떠올릴 수 있는 비교 기준 게임을 한 개 이상 선택한다.
- 플레이 시간은 충분한 플레이 경험 조건을 확인하고 비교 기준 후보를 정렬하는 데 사용한다. 플레이 시간이 가장 긴 게임을 자동으로 선호 게임으로 판단하지 않는다.
- 사용자는 게임마다 자신에게 관련 있는 상위 경험 영역을 고른다.
- 선택한 상위 경험 영역마다 개인화에 중요한 하위 특성을 최대 3개까지 고르고, 각 특성이 긍정적이었는지 부정적이었는지 구분한다.
- 모든 상위 경험 영역을 평가하도록 강제하지 않는다.
- 긍정·부정을 구분한 하위 특성이 한 개 이상 있어야 해당 게임의 경험 평가를 완료한 것으로 본다.

### 개인화 비교

- 비교 기준 게임 한 개 평가를 완료하면 제한된 근거로 개인화 비교를 제공한다.
- 비교 기준 게임 3개 이상 입력을 권장한다. 1~2개이면 항상 개인화 데이터가 부족하다고 안내하며, 3개 이상이어도 선택한 특성의 반복과 범위가 부족하면 안내를 유지한다.
- 후보 게임의 하위 특성을 사용자가 직접 입력한 취향과 비교한다.
- 마이페이지에서 비교 기준 게임과 하위 특성 평가를 확인하고 수정할 수 있다.
- 평가를 수정하면 최신 사용자 입력을 기준으로 개인화 결과를 다시 계산한다.
- 수정으로 완료된 비교 기준 게임이 없어지면 개인화 결과를 제공하지 않고 기본 리뷰 분석과 등록 안내를 제공한다.
- 종합 적합도 점수는 제공하지 않는다.
- 결과를 `맞을 근거`, `주의 신호`, `판단 불가`로 구분한다.
- 가장 강한 `맞을 근거`와 `주의 신호`를 결과 상단에서 함께 비교할 수 있게 제공하고, 그 뒤에 상대적으로 약한 신호를 배치한다.
- 사용자에게 중요한 긍정·부정 특성이지만 리뷰 근거가 부족한 항목은 별도의 `판단 불가` 목록으로 제공한다. 부정적으로 평가한 특성은 잠재적인 주의 항목임을 함께 표시한다.
- 각 결과에 판단 근거가 된 실제 리뷰를 연결한다.
- 관련 리뷰가 한 개 이상 있지만 충분하지 않거나 서로 충돌하면 `판단 불가`로 표시한다.
- 관련 리뷰를 찾지 못한 특성은 개인화 결과 항목으로 만들지 않고, 현재 분석에서 근거를 찾지 못했다고 안내한다.
- `맞을 근거`, `주의 신호`, `판단 불가` 중 비어 있는 결과 그룹은 표시하지 않는다. 세 그룹이 모두 비어 있으면 현재 근거로 개인화 비교를 만들 수 없다고 안내하고 기본 리뷰 분석을 제공한다.

### 구매 판단 관리

- 분석한 게임을 `구매 후보`, `보류`, `제외` 중 하나로 저장한다.
- 마이페이지에서 상태별 게임 목록을 확인한다.
- 상태는 사용자의 직접 판단이며 시스템이 자동으로 결정하지 않는다.

## MVP 제외 범위

- 사용자의 취향에 맞는 게임을 자동으로 추천하는 피드
- 두 개 이상의 후보 게임을 직접 비교하는 기능
- 모든 Steam 장르와 게임 지원
- Steam에 등록되지 않은 콘솔 전용 게임 등록
- 가격 변동, 할인 알림, 위시리스트 자동 연동
- 친구와 게임 취향 비교
- 사용자 요청 시 실행하는 실시간 리뷰 분석
- 리뷰의 과거·최근 추세 비교와 패치 전후 변화 판단
- 머신러닝 추천 모델과 파인튜닝
- 관리자용 리뷰 라벨링·분석 관리 도구
- 실제 구매 여부와 장기 플레이 결과 자동 추적
- 구매 판단에 대한 자유 메모
- 외부 웹진이나 다른 플랫폼의 게임 정보 크롤링

## 성공 기준

### 기능적 성공 기준

- 로그인하지 않은 사용자가 8개 게임의 기본 리뷰 분석과 근거를 확인할 수 있다.
- 비교 기준 게임을 한 개 평가한 사용자가 근거 부족 안내와 함께 개인화 비교를 시작하고 구매 상태 저장까지 대표 흐름을 완료할 수 있다.
- 사용자가 관련 있는 상위 경험 영역에서 하위 특성을 최대 3개까지 선택해 긍정·부정 경험을 구분할 수 있다.
- 일부 상위 경험 영역만 선택한 상태로 경험 평가를 완료하고 개인화 비교를 시작할 수 있다.
- 사용자가 강한 `맞을 근거`와 `주의 신호`, 약한 신호, `판단 불가` 항목의 차이를 확인할 수 있다.
- 한쪽 결과 그룹이나 모든 개인화 결과가 비어 있어도 사용자가 현재 근거 상태와 기본 리뷰 분석을 확인할 수 있다.
- 과거 경험 평가를 수정하면 개인화 결과가 최신 입력을 반영한다.
- 비교 기준 게임이 없는 사용자도 기본 리뷰 분석을 이용할 수 있으며, 개인화를 시작하는 방법을 안내받는다.
- 모든 개인화 결과에 실제 리뷰 근거가 연결된다.
- 핵심 사용자 흐름에 대한 E2E 테스트가 통과한다.

### 사용자 가치 검증 기준

소울라이크 경험이 있는 사용자 3명 이상에게 다음을 확인한다.

- 기본 분석이 Steam 개별 리뷰보다 게임의 장단점을 빠르게 파악하는 데 도움이 되는가?
- 과거 경험과의 비교가 구매 판단에 실질적인 영향을 주는가?
- `맞을 근거`, `주의 신호`, `판단 불가`의 차이를 이해할 수 있는가?
- 실제 리뷰 근거가 분석 결과를 신뢰하는 데 도움이 되는가?
- 분석 전보다 `구매 후보`, `보류`, `제외` 중 하나를 더 명확하게 선택할 수 있는가?

게임을 실제로 구매하고 장시간 플레이했는지는 장기 검증 항목으로 분리한다.

## 구현 전 결정할 정책

다음 항목은 제품 범위를 바꾸지 않는 세부 정책이므로 구현 전에 별도로 검증하고 결정한다.

- 7~8개 수준으로 구성할 상위 경험 영역의 최종 개수·명칭과 장르 공통 하위 특성
- 사용자 경험의 긍정·부정과 후보 게임 리뷰 특성의 방향·맥락을 `맞을 근거`, `주의 신호`, `판단 불가`로 연결하는 판정표
- 반복 언급 수, 독립적인 리뷰 수와 상충 근거를 반영한 신호 강도·정렬 기준
- 비교 기준 게임이 3개 이상일 때 특성의 반복·범위로 데이터 충분성을 판단하는 기준
- 개인화 데이터 부족 안내의 문구·강도와 추가 입력 경로의 표시 방식
- 충분한 플레이 경험으로 인정할 정확한 시간 기준
- 온보딩에 사용할 소울라이크·인접 장르 비교 기준 게임 목록
- 리뷰 표본 수, 언어 구성, 최신성 기준과 갱신 주기
- 사용자 인증, 데이터 저장, API, 데이터베이스, 세부 아키텍처
