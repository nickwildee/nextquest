# NextQuest 프로젝트 컨텍스트

## 한 문장 정의

NextQuest는 소울라이크 게임 구매를 고민하는 사용자가 검수된 리뷰 분석과 자신의 과거 플레이 경험을 비교해, 후보 게임이 어떤 요소에서 취향과 일치하거나 충돌하는지 판단하도록 돕는 서비스다.

## 프로젝트 배경

Steam의 할인율, 인기 순위, 전체 평가는 게임을 발견하는 데에는 유용하지만, 사용자가 과거에 즐긴 플레이 경험과 새로운 게임의 관계를 충분히 설명하지 못한다.

구매 가격이 높고 플레이 시간이 긴 게임일수록 사용자는 여러 리뷰, 커뮤니티, 영상 콘텐츠를 확인한다. 하지만 정보가 여러 곳에 흩어져 있고, 서로 다른 의견이 자신의 취향과 어떤 관계가 있는지 판단하기 어렵다. 그 결과 구매 결정을 반복해서 미루거나, 구매한 게임을 실제로 플레이하지 않는 문제가 생길 수 있다.

NextQuest는 새로운 게임을 자동으로 추천하는 서비스가 아니다. 사용자가 이미 구매 후보로 고려하는 게임을 더 깊게 검토하도록 돕는 의사결정 지원 서비스다.

NextQuest의 우선 목표는 실제 사용자가 구매 판단에 활용할 수 있는 작은 서비스를 제공하는 것이다. 포트폴리오와 학습 성과는 이 사용자 가치를 구현하는 과정에서 얻는 부가 결과로 둔다.

## 해결하려는 문제

핵심 사용자는 다음과 같은 불확실성을 겪는다.

- 유명하고 평가가 좋은 게임이 자신의 과거 경험과 어떤 점에서 비슷하거나 다른지 알기 어렵다.
- 개별 리뷰만 읽어서는 반복적으로 언급되는 장점과 단점을 한눈에 파악하기 어렵다.
- 전체 평점은 게임의 전반적인 반응을 보여주지만, 특정 특성이 사용자에게 장점인지 주의할 요소인지 설명하지 못한다.
- 여러 출처를 직접 비교하는 데 시간이 많이 들고, 확인한 정보가 구매 판단으로 연결되지 않는다.

## 핵심 사용자

MVP의 핵심 사용자는 다음 조건을 가진 사람이다.

- 소울라이크 게임에 관심이 있고 새로운 구매 후보를 찾고 있다.
- 소울라이크 또는 전투 경험을 비교할 수 있는 인접 장르를 충분히 플레이했다.
- 게임을 구매하기 전에 리뷰와 커뮤니티 정보를 적극적으로 확인한다.
- 단순 평점보다 전투 감각, 탐험 방식, 빌드 다양성과 같은 구체적인 경험 특성을 중요하게 생각한다.

충분한 비교 경험이 없는 사용자도 게임별 기본 리뷰 분석은 볼 수 있다. 개인화 비교는 충분히 플레이한 과거 게임을 최소 3개 등록하고, 각 게임의 모든 상위 경험 영역에서 하위 특성 평가 또는 `경험 부족` 처리를 완료한 로그인 사용자에게 제공한다.

## 핵심 가치

### 근거 중심의 리뷰 분석

긍정·부정 리뷰에서 반복적으로 언급되는 플레이 특성을 구조화한다. 각 분석 항목에는 사용자가 직접 확인할 수 있는 실제 리뷰 근거를 연결한다.

### 과거 경험과의 비교

사용자가 과거 게임의 상위 경험 영역을 모두 확인하고, 경험한 영역에서는 중요하게 느낀 하위 특성을 최대 3개까지 골라 `좋았음` 또는 `아쉬웠음`으로 구분한다. 같은 영역 안에서 좋아한 특성과 아쉬웠던 특성을 함께 선택할 수 있다. 후보 게임의 리뷰 특성과 비교하되 결과는 종합 점수가 아니라 특성별 근거로 제공한다.

### 불확실성의 명시

분석 결과는 `맞을 근거`, `주의 신호`, `판단 불가`로 구분한다. 한 상위 영역에 맞을 근거와 주의 신호가 동시에 존재할 수 있다. 관련 리뷰가 부족하거나 서로 충돌하거나 비교할 특성을 찾지 못하면 결론을 강요하지 않고 해당 하위 특성을 `판단 불가`로 표시한다.

## 핵심 개념

- **분석 대상 게임**: 사용자가 구매를 고민하며 NextQuest가 리뷰 분석 결과를 제공하는 게임
- **비교 기준 게임**: 사용자가 과거에 충분히 플레이했고 개인 취향을 입력하는 게임
- **기본 리뷰 분석**: 로그인이나 개인화 조건 없이 누구나 확인할 수 있는 게임 자체의 리뷰 분석
- **개인화 비교**: 비교 기준 게임에서 입력한 취향과 분석 대상 게임의 특성을 대조한 결과

Steam은 게임 식별자와 상점 등록 여부를 확인하는 기준으로 사용한다. 비교 기준 게임은 사용자가 플레이한 플랫폼이나 언어와 관계없이 검수 목록과 플레이 경험 조건으로 판단한다. Steam 계정 연동은 fixture 프로토타입 이후 라이브러리와 플레이 시간을 편리하게 불러오기 위한 확장 기능이다.

## 대표 사용 시나리오

사용자는 구매를 고민하는 소울라이크 게임의 기본 리뷰 분석을 살펴본다. 개인화가 필요하면 로그인하고 충분히 플레이한 과거 게임을 최소 3개 등록한다. 각 게임의 모든 상위 경험 영역을 확인하고, 경험한 영역에서는 중요한 하위 특성의 호불호를 입력하며 충분히 경험하지 않은 영역은 `경험 부족`으로 처리한다. 조건을 충족한 모든 비교 기준 게임이 개인화에 사용된다.

사용자는 후보 게임의 상위 경험 영역과 하위 특성별 `맞을 근거`, `주의 신호`, `판단 불가`와 실제 리뷰 근거를 확인한다. 한 영역에 긍정 신호와 주의 신호가 함께 나타날 수 있으며, 기본 3개의 근거를 보고 필요하면 최대 10개까지 펼친다. 이후 후보 게임을 `구매 후보`, `보류`, `제외` 중 하나로 저장하고 과거 경험 평가를 수정할 수 있다.

## 제품 원칙

- 추천보다 사용자의 구매 판단을 돕는다.
- 종합 점수로 근거보다 정밀해 보이는 결론을 만들지 않는다.
- 사용자가 직접 선택하고 호불호를 표시한 하위 특성만 취향 근거로 사용한다.
- 취향을 별도로 추측하거나 중복 입력받지 않고, 사용자가 수정한 과거 경험 평가를 개인화 결과에 반영한다.
- 모든 상위 경험 영역을 확인하게 하되, 경험하지 않은 영역은 `경험 부족`으로 완료하고 취향 계산에서 제외한다.
- 하나의 상위 경험 영역에 긍정·부정 하위 특성을 함께 저장할 수 있다.
- 특성이 나타난 게임 수와 사용자의 선호 일관성을 분리해 표시하고, 단일 점수로 합치지 않는다.
- 분석 근거가 부족하면 억지로 결론을 내리지 않는다.
- Steam 이외의 웹진이나 플랫폼 데이터를 MVP의 필수 출처로 확장하지 않는다.
- 검수 가능한 작은 게임 목록으로 시작하고, 품질을 확인한 뒤 범위를 넓힌다.

## 장기 방향

MVP는 소울라이크 중심의 소수 게임으로 시작한다. 리뷰 분석 품질과 개인화 비교의 유용성을 검증한 뒤 인접 장르로 분석 대상을 확장하고, 장기적으로는 같은 근거 중심 비교 방식을 여러 장르에 적용한다.
