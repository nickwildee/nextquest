# NextQuest 프로젝트 컨텍스트

## 한 문장 정의

NextQuest는 소울라이크 게임 구매를 고민하는 사용자가 검수된 리뷰 분석과 자신의 과거 플레이 경험을 비교해, 후보 게임이 어떤 요소에서 취향과 일치하거나 충돌하는지 판단하도록 돕는 서비스다.

## 프로젝트 배경

Steam의 할인율, 인기 순위, 전체 평가는 게임을 발견하는 데에는 유용하지만, 사용자가 과거에 즐긴 플레이 경험과 새로운 게임의 관계를 충분히 설명하지 못한다.

구매 가격이 높고 플레이 시간이 긴 게임일수록 사용자는 여러 리뷰, 커뮤니티, 영상 콘텐츠를 확인한다. 하지만 정보가 여러 곳에 흩어져 있고, 서로 다른 의견이 자신의 취향과 어떤 관계가 있는지 판단하기 어렵다. 그 결과 구매 결정을 반복해서 미루거나, 구매한 게임을 실제로 플레이하지 않는 문제가 생길 수 있다.

NextQuest는 새로운 게임을 자동으로 추천하는 서비스가 아니다. 사용자가 이미 구매 후보로 고려하는 게임을 더 깊게 검토하도록 돕는 의사결정 지원 서비스다.

## 해결하려는 문제

핵심 사용자는 다음과 같은 불확실성을 겪는다.

- 유명하고 평가가 좋은 게임이 자신의 과거 경험과 어떤 점에서 비슷하거나 다른지 알기 어렵다.
- 개별 리뷰만 읽어서는 반복적으로 언급되는 장점과 단점을 한눈에 파악하기 어렵다.
- 전체 평점은 게임의 전반적인 반응을 보여주지만, 특정 특성이 사용자에게 장점인지 주의할 요소인지 설명하지 못한다.
- 여러 출처를 직접 비교하는 데 시간이 많이 들고, 확인한 정보가 구매 판단으로 연결되지 않는다.

## 핵심 사용자

MVP의 핵심 사용자는 다음 조건을 가진 사람이다.

- 소울라이크 게임에 관심이 있고 새로운 구매 후보를 찾고 있다.
- 소울라이크 또는 전투 경험을 비교할 수 있는 인접 장르를 충분히 플레이했다.
- 게임을 구매하기 전에 리뷰와 커뮤니티 정보를 적극적으로 확인한다.
- 단순 평점보다 전투, 조작, 보스전, 탐험, 성장·빌드, 파밍·반복 플레이와 같은 구체적인 경험 요소를 중요하게 생각한다.

충분한 비교 경험이 없는 사용자도 게임별 기본 리뷰 분석은 볼 수 있다. 다만 개인화 비교는 기준을 충족한 과거 게임을 최소 3개 평가한 뒤에만 사용할 수 있다.

## 핵심 가치

### 근거 중심의 리뷰 분석

긍정·부정 리뷰에서 반복적으로 언급되는 플레이 특성을 구조화한다. 각 분석 항목에는 사용자가 직접 확인할 수 있는 실제 리뷰 근거를 연결한다.

### 과거 경험과의 비교

사용자가 과거 게임에서 좋았거나 아쉬웠던 요소를 후보 게임의 리뷰 분석 결과와 비교한다. 결과는 종합 점수가 아니라 요소별 근거로 제공한다.

### 불확실성의 명시

분석 결과는 `맞을 근거`, `주의 신호`, `판단 불가`로 구분한다. 사용자 경험이나 리뷰 근거가 부족하거나 서로 충돌할 때는 결론을 강요하지 않고 `판단 불가`로 표시한다.

## 핵심 개념

- **분석 대상 게임**: 사용자가 구매를 고민하며 NextQuest가 리뷰 분석 결과를 제공하는 게임
- **비교 기준 게임**: 사용자가 과거에 충분히 플레이했고 개인 취향을 입력하는 게임
- **기본 리뷰 분석**: 로그인이나 개인화 조건 없이 누구나 확인할 수 있는 게임 자체의 리뷰 분석
- **개인화 비교**: 비교 기준 게임에서 입력한 취향과 분석 대상 게임의 특성을 대조한 결과

Steam은 게임 식별자, 상점 등록 여부, 한국어 인터페이스 지원 여부를 확인하는 기준으로 사용한다. Steam 계정 연동은 필수가 아니라 라이브러리와 플레이 시간을 편리하게 불러오는 수단이다.

## 대표 사용 시나리오

사용자는 구매를 고민하는 소울라이크 게임의 기본 리뷰 분석을 살펴본다. 더 구체적인 비교가 필요하면 Steam 라이브러리를 연결하거나 과거에 다른 플랫폼에서 플레이한 게임을 직접 등록한다. 충분히 플레이한 게임 3개 이상에서 6개 경험 요소를 평가하면 개인화 비교가 활성화된다.

사용자는 후보 게임의 요소별 `맞을 근거`, `주의 신호`, `판단 불가`와 실제 리뷰 근거를 확인한다. 이후 게임을 `구매 후보`, `보류`, `제외` 중 하나로 저장하고 마이페이지에서 다시 확인한다. 과거 게임에 대한 평가가 달라졌다면 마이페이지에서 6개 요소의 입력을 수정하며, 개인화 결과는 최신 입력을 기준으로 다시 계산된다.

## 제품 원칙

- 추천보다 사용자의 구매 판단을 돕는다.
- 종합 점수로 근거보다 정밀해 보이는 결론을 만들지 않는다.
- 사용자가 명시적으로 입력한 `좋았음`과 `아쉬웠음`만 취향 근거로 사용한다.
- 취향을 별도로 추측하거나 중복 입력받지 않고, 사용자가 수정한 과거 경험 평가를 개인화 결과에 반영한다.
- 분석 근거가 부족하면 억지로 결론을 내리지 않는다.
- Steam 이외의 웹진이나 플랫폼 데이터를 MVP의 필수 출처로 확장하지 않는다.
- 검수 가능한 작은 게임 목록으로 시작하고, 품질을 확인한 뒤 범위를 넓힌다.

## 장기 방향

MVP는 소울라이크 중심의 소수 게임으로 시작한다. 리뷰 분석 품질과 개인화 비교의 유용성을 검증한 뒤 인접 장르로 분석 대상을 확장하고, 장기적으로는 같은 근거 중심 비교 방식을 여러 장르에 적용한다.
